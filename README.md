# location-simulator
A way to simulate location without using Xcode.


Debugger-
As part of a feasibility survey- I have created the debugger, with the assistance of AI tools. This is to prevent ultimately a big waste of time- as I could be weeks into my project before realising it's not possible due to OS limitations.
The debugger will be tested with an accessory that does give false GPS signals, and as it's an accessory and not software, the 'software' tag won't be deemed true.
It records core location, and there is a feature to mark events, such as connecting to an accessory, or disconnecting. Once completed, there is a feature to export your results to CSV.
